# 空中的弦

用雙手在攝影機前拉出一條懸在空中的弦，換不同的材質，聽聽真實物理算出來的聲音。
給國小自然課（聲音單元）、音樂課與展覽活動使用的網頁互動教具。

互動的點子來自鄭各均的科技藝術作品（靈感來自 Pat Metheny 的 42 弦吉他）。

## 怎麼玩

用 Chrome 或 Edge 開啟網頁，按「開始」並允許使用攝影機。影像只在這台裝置上運算，不會上傳。

| 動作 | 手勢 |
|------|------|
| 拉出新弦 | 兩手同時把拇指和食指捏起來，拉開，放開 |
| 撥弦 | 伸出食指掃過弦，動作越快撥得越用力 |
| 改長度（改音高） | 單手捏住弦的端點拖動 |
| 整條搬移 | 單手捏住弦的中段拖動 |
| 剪斷 | 食指和中指比剪刀，把弦夾在中間再合起來 |
| 止音 | 張開手掌按在弦上 |
| 泛音 | 一根手指輕輕停在弦的 1/2 或 1/3 處，另一隻手去撥 |
| 換材質 | 食指在上方的材質上停一下 |

沒有攝影機也能玩：開始畫面選「改用滑鼠操作」。平板可以用觸控：兩指之間拉出新弦，單指劃過是撥弦。

### 兩種模式

- **教學模式**：顯示長度、頻率、音名，可以調整張力與粗細，有任務卡（國小、國中各 7 張）和慢動作。
- **展覽模式**：只留弦與特效，放手時自動對準五聲音階，怎麼拉都好聽。

快捷鍵：`M` 切換模式、`S` 慢動作、`F` 全螢幕、`C` 全部清除、`Delete` 剪斷選取的弦。

### 網址參數

| 參數 | 作用 |
|------|------|
| `?mode=exhibit` | 直接以展覽模式開啟 |
| `?grade=junior` | 年級：`elementary` 國小（預設）、`junior` 國中以上 |
| `?hand=child` | 手的大小：`child` 小朋友、`adult` 大人（預設） |
| `?debug=1` | 顯示追蹤速度、指距、畫質等級 |

## 物理

弦的音高、音色和延音都由材料參數算出來，沒有使用錄音：

- 基頻 `f = (1/2L)·√(T/μ)`，由弦長、張力、線密度決定
- 彎曲剛性讓泛音略高於整數倍（非諧性）
- 空氣阻力、材料內耗、端點損耗決定每個泛音衰減多快
- 撥弦的位置決定各泛音的強度，張力超過抗拉強度弦就會斷

模型採用的假設與每一項設計決定，記錄在 [DESIGN_DECISIONS.md](DESIGN_DECISIONS.md)；網頁裡按「說明」也看得到給學生的版本。

## 開發

需要 Node.js 22 以上。

```bash
npm install
npm run dev      # 開發伺服器，http://localhost:5173
npm test         # 單元測試（物理公式、聲音合成、手勢規則、任務卡）
npm run build    # 產出 dist/，可放到任何靜態網站空間
```

推送到 `main` 分支時，GitHub Actions 會自動測試、建置並發布到 GitHub Pages。

手部追蹤使用 [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)（Apache 2.0），模型檔與執行檔都包在專案裡，不依賴外部網站。
